# Website database (`content` branch)

This branch is the Coding Club website's **database**. It holds no code.

- `content/site.json`: projects, team, events and updates
- `uploads/`: images uploaded from the admin portal

**Don't edit by hand.** Change content at `/admin` on the website; every save is a commit here.
The code lives on `main`. Vercel never deploys this branch.
